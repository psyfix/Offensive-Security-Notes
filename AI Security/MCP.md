Model -  Refers to the LLM - Claude, GPT-4
Context - Memory/Scope Capabilities, Tools
Protocol - Communication Layer

All together the Model (LLM) gets Context (Capabilities Tools) to help it process data and use a Protocol to communicate this over.

MCP Standardised the way AI is being developed and integrated.

Basically an API for LLMs.

Three important aspects:

Resources - Access to Data
- Files, databases emails and cloud storage

Tools - Ability to take actions
- MCP tools execute commands, call functions and modify systems

Prompts 
- Templates, instructions and behaviour modifications
